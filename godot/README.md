# Nightclub City — Godot Rebuild

This folder is the clean Godot 4 rebuild of Nightclub City.

## Open in Godot
Import `godot/project.godot` from the repository.

## Current foundation
- Godot 4 project
- 1280×720 reference viewport
- Compatibility renderer for broad Mac support
- Main scene and startup script
- Clean folders for scenes and scripts

The older Phaser/web prototype remains outside this folder for reference and is not overwritten.
