# Placement Foundation Test

This is a deliberately tiny Godot 4 test project for validating furniture placement before any nightclub art is added.

## What it proves
- Fixed 64x64 logical grid
- Exact cell snapping
- 1x1, 2x1, and 2x2 footprints
- Occupied-cell collision blocking
- Rotation for rectangular footprints
- Right-click removal
- Visual valid/invalid placement preview

## Controls
- **1** = select 1x1 object
- **2** = select 2x1 object
- **3** = select 2x2 object
- **R** = rotate selected footprint
- **Left click** = place
- **Right click** = remove the object under the cursor

## Run it
Open the `placement_test` folder as a Godot project and press **F6/F5**.

Do not add real furniture art until this placement behavior is confirmed to work correctly.
